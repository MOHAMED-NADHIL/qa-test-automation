# QA Test Automation Framework

A professional web test automation framework built using Playwright and TypeScript. 
This project demonstrates automated functional testing, validation testing, and regression testing for a web application.

## 🚀 Tech Stack

- Playwright
- TypeScript
- Node.js
- Git & GitHub
- GitHub Actions
- VS Code

## 🧪 Test Coverage

### Login Testing

- Valid username and password
- Invalid password
- Invalid username
- Empty username
- Empty password
- Empty username and password
- Invalid login validation

### Registration Testing

- Valid registration
- Invalid email format
- Required field validation
- Registration form validation
